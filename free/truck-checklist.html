Weekly truck and trailer checklist (free, printable)

Running more than one truck? Print one sheet for each, name one person to look after each truck, and give every check five minutes a week.

The truck checklist

Vehicles and week

Each vehicle gets its own A4 sheet: a truck, ute, van or trailer. Running one truck? One sheet a week is plenty.

Leave it empty to write the date on each sheet by hand.

Checklist lines

These lines print on every sheet. Rename, reorder or remove any of them, or add your own, up to 25 lines of 80 characters each. A blank line prints as an empty row to write in.

    In the print window, choose Save as PDF as the destination if you want a file, and turn off Headers and footers so only the sheets print. Each vehicle prints on its own A4 sheet, with no website menus. What you type stays in this page.

    The routine

    How to run a weekly truck check in five minutes.

    1. Pick a day. Keep it the same every week. The end of the working day on Friday and first thing on Monday both work.
    2. Name one person for each truck. One sheet for each truck, and one person whose job it is to do the check and put their name on the Checked by line. With one truck, that is you.
    3. One tick per line. Walk round the truck once and tick each line as you do it. If you did not do it, do not tick it.
    4. Write down problems. Anything damaged, missing or worn goes in the notes box, with what needs doing.
    5. Keep twelve weeks of sheets. Clip each week's sheets into a folder. Twelve weeks side by side make it easy to spot the same problem coming up again.

    A weekly check keeps the truck tidy and catches small problems early. It is not a safety inspection.

    Keeping it going

    Make it a habit.

    Printing the sheets is the easy part. Two things help them get filled in every week: one named person for each truck, and someone noticing when a sheet is finished.

    If you run two or more trucks, you could add a small weekly recognition for the crew member who hands in a finished sheet. A coffee on you, or a thank-you at the Friday catch-up, is plenty. It is optional, and it is your call as the owner. It only makes sense with two or more trucks, because it is the sheets side by side that let everyone see whose is done.

    With one truck, the sheet is the habit. Tick it, then put the kettle on.

    Questions

    Good to know.

    Is this only for businesses with several trucks?

    No. It is written for crews that run two or more trucks, where a sheet and a named person for each truck keep things from slipping. If you run one truck, choose 1 vehicle: one sheet a week is plenty.

    Is the truck checklist free?

    Yes. There is nothing to sign up for. Fill it in, then print it or save it as a PDF.

    Does it keep what I type?

    No. It all stays in this page in your browser. Nothing is sent anywhere or saved, so reloading the page clears it. Save a PDF of the sheets before you leave.

    How do I print one sheet for each truck?

    Choose how many vehicles, type each name or rego, then press Print or save as PDF. Each vehicle gets its own A4 sheet. In the print window, choose Save as PDF as the destination if you want a file, and turn off Headers and footers so only the sheets print.
