How to use it

Four steps, then print.

  1. Choose your trade. The lines fill with example services for that trade.
  2. Type the quantity and price for each line. Add, change or remove lines. The totals update as you go.
  3. Switch on Add GST (10%) if you charge GST. Each line is rounded to the nearest cent, and so is the GST, with half a cent rounded up.
  4. Press Print or save as PDF. Everything stays in this page, so a reload clears it. Save the PDF before you leave.
Questions

Good to know.

Is this quote template free?

Yes. There is nothing to sign up for. Fill it in, then print it or save it as a PDF.

Does it keep what I type?

No. It all stays in this page in your browser. Nothing is sent anywhere or saved, so reloading the page clears it. Save a PDF of the quote before you leave.

How is the GST worked out?

With Add GST (10%) on, the GST is a tenth of the subtotal, rounded to the nearest cent with half a cent rounded up. Each line (quantity times price) is rounded the same way before the lines are added up. With it off, the total is the subtotal. The GST calculator shows the sums.

How do I save the quote as a PDF?

Press Print or save as PDF, then choose Save as PDF as the destination in the print window. Turn off Headers and footers there so the page address and date are left off. The page is set up for A4 with no website menus.
